Privacy policy of Sewer Pipes

What data

The game does not collect personal data, store it on servers or share it with third parties. It has no accounts and no in-app purchases, for now it has no ads and no statistics, and it does not need the internet. For now the only part that goes online is the built-in RuStore rating SDK in the RuStore version (see "Rating the game"). Both versions (RuStore and AppGallery) contain the Yandex ad SDK, but it is switched off and never started (see "Ads"); statistics and crash reports are switched off too (see "Statistics and crashes"). So the AppGallery version does not go online for now.

What stays on your device

Progress, settings and rewards are stored only on your device so you can continue playing. The developer has no access to them.

Reminders

Only if you agree, the game asks the phone for permission to show notifications and sets a local reminder: only after 7 days without opening the game, at most 3 times (after 7, 14 and 21 days), never at night. The phone shows it on schedule by itself, without the internet or any server; no data is sent anywhere. The permission to run after a restart is used only to set the reminder again. You can turn it off in the game's or the phone's settings at any time.

How long and how to delete

The data is kept while the game is installed. To delete it, uninstall the game or clear its data in the phone settings (Settings → Apps → Sewer Pipes → Storage → Clear data).

Rating the game

In the RuStore version, the "Rate the game" button and an occasional offer to rate the game open RuStore's official rating dialog. It is shown by the RuStore rating SDK (VK LLC) built into the game; if the dialog is unavailable, the button opens the game's RuStore page instead. You leave your rating and review in the RuStore app under your RuStore account, and RuStore handles them under its own terms: https://www.rustore.ru/help/legal/privacy-policy-users.

Each time the RuStore version starts, and if the rating dialog fails to open, the SDK sends technical metrics to a RuStore server (stats-dg.rustore.ru): the game's package name and version, the SDK's name and version, the event type and its time, error details if something failed, and a random installation ID that the SDK creates on your device. This ID is not linked to your phone model, your account or your advertising ID, and it is removed when you uninstall the game or clear its data. As with any internet connection, the server sees your IP address. Without internet, the metrics wait on the device and are sent later by a daily background task, including after the phone restarts. That is why the RuStore version needs the permissions to access the internet, check the network state and run after a restart. These metrics contain no name, phone number, email, advertising ID, phone model, location or game progress. RuStore keeps them as its terms say.

The AppGallery version has no RuStore SDK: "Rate the game" opens the game's AppGallery page. The game does not receive your data from the store.

Ads

Both versions of the game contain the Yandex Mobile Ads SDK (Yandex Advertising Network, YANDEX LLC) with the VK Ads adapter (myTarget, VK LLC), through which Yandex may fill some ads with VK Ads. Ads are switched off in the game for now: the game does not start these SDKs, they contact no server and send nothing, and the AppMetrica analytics built into the Yandex SDK is turned off. The AppGallery version has the permissions to access the internet and check the network state only because of this SDK.

If we turn ads on in an update, this policy will change before that update is out. Ads will then be non-personalised only: the game already puts the SDK into its child-audience mode without interest targeting and does not pass on the advertising ID (the permission for it is removed from the game). To show and count ads, the SDK will receive the device model, Android version, language, IP address and ad impression and click data; VK Ads may use the MyTracker ID to count ad impressions and clicks. The ad networks process this data under their own rules: Yandex: https://yandex.ru/legal/confidential/ (SDK terms: https://yandex.ru/legal/mobileads_sdk_agreement/), VK: https://help.mail.ru/legal/terms/adsvk/privacy/. The game itself does not store this data.

Statistics and crashes

The MyTracker statistics and Tracer crash report services (VK LLC) are switched off in this version of the game: it has no keys for them, Tracer is not in the game, and the game does not start the MyTracker library that comes with the VK Ads adapter. No statistics or crash reports are sent anywhere. If we turn them on, this policy will change before that update is out.

Writing to the developer

"Write to the developer" opens your mail app; you send the email yourself. Your address and message are used only to reply and are deleted on request.

Your rights

You can delete the game's data at any time (see above) and write to us with any question about data or to have your emails deleted. The game works fully without the internet: if your phone allows it, you can block its network access (Settings → Apps → Sewer Pipes → Data usage).

Children

The game is suitable for all ages and does not collect children's data.
